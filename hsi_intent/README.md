# HSI Intent Field v1.1 — Pleiadian Blue Ideal

HSI Intent Field turns long-running project goals, invariants, hypotheses and claim boundaries into a finite, canonical registry checked alongside ordinary HSI state-transition certificates.

## One Blue, many possibilities

The registry now defines **PLEIADIAN-BLUE / 昴宿星團的藍** as a symbolic teleological ideal: a shared form of the good / normative attractor across plural admissible possibilities.

It is intentionally **not** an astronomical-causation claim, extraterrestrial claim, physical field, prediction, or guarantee. "Blue" is protocol language for a shared normative invariant.

Different worldlines may have different `transition_uid` values while sharing the same `blue_uid`. The current Blue dimensions are:

- Agency
- Non-coercion
- Truthfulness / claim separation
- Care / wellbeing
- Dialogue and repair
- Continuity / provenance

A certificate closes only when every Blue dimension has explicit evidence through preserved or advanced anchor atoms, no Blue anchor is violated, no active hard invariant is violated, and no unknown intent atom is referenced.

Thus:

```text
One Blue
  -> many goals
  -> many strategies
  -> many possible worldlines
  -> one shared normative invariant
```

The system does **not** require all admissible possibilities to converge to one physical state or one policy.

## Claim discipline

Conversation text is not treated as truth. GOAL, INVARIANT, HYPOTHESIS and CLAIM_BOUNDARY remain distinct. Persistent atoms carry provenance and may only be removed from active use through explicit status transitions such as SUPERSEDED, REJECTED or DEPRECATED.

The field is non-executing: it has no authority to place trades, change deployment modes, control people, or assert that a modeled trajectory will occur in reality.
