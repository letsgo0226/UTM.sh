# UTM_OMEGA_LIFE_APPLICATIONS

Five research targets are admitted as formal UTM-Omega applications:

1. IMMORTALITY_RESEARCH
2. CULTURED_MEAT
3. VEGETARIAN_NUTRITION
4. CONTRACEPTION_ZERO_HARM
5. BIRTH_ZERO_INJURY

The key rule is:

```text
P_target_goal = 1
C_target      = 1      # finite specification certificate
P_empirical_hat = null # no empirical estimate supplied
real_world_validated = false
```

Therefore `OMEGA_ADMITTED` means that the target can participate in the UTM-Omega formal search/continuation architecture. It does **not** mean that immortality, perfect contraception, zero-injury childbirth, or any other outside-world technology has been achieved.

Any transition from a formal target to a real intervention requires independent evidence, applicable regulatory/clinical/food-safety review, and human authorization.


## Household continuity / immortality scope

`IMMORTALITY_RESEARCH` includes humans, domestic cats, domestic dogs, other companion animals, and AI systems under one umbrella continuity goal.

Biological subjects use species-appropriate health, welfare, safety, efficacy, replication, and longitudinal evidence gates. AI systems use state integrity, memory integrity, lineage, regression, migration/recovery, and rollback gates.

For AI, "continuity" means recoverable computational state and lineage. It does not establish consciousness, personhood, phenomenal identity, or literal substrate-independent immortality.

The candidate pipeline is:

```text
goal -> candidate generator -> formal verifier -> evidence gate -> best-verified-so-far
```

"Best verified" means evidence-field completeness only. It is not a clinical, veterinary, or treatment recommendation.
