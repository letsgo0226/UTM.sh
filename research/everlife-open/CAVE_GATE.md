# The Cave Gate: an epistemic review before publication or deployment

**Why:** Plato, Republic VII (514a–521b), describes education through turning away from shadows; here this is **an analogy**, not a claim about AI subjective consciousness. Models, simulated results, language outputs, and GitHub CI must not be mistaken for independent observations of the external world.

**Research path:** `G257/ATGC → bounded virtual model → evidence/provenance review → falsification plan → independent observation when available → human authorization → safe deployment`.

NIST AI RMF supports continuous GOVERN / MAP / MEASURE / MANAGE risk management (NIST AI 100-1): https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-ai-rmf-10

## Files

- `epistemic_claims.json`: a bounded set of machine-readable claims with an explicit question, evidence tier, and proposed falsification check.
- `epistemic_gate.py`: reject formally unsupported claims, empirical claims upgraded without evidence, automatic AI-identity claims, and unverified real-time Railway status. Claims receive reversible G257 IDs and SHA-256 fingerprints.
- `public/epistemic-review.json`: CI-calculated classifications; this is a **historical snapshot** and is not a proof of awareness or of the claims' real-world truth.
- `test_epistemic_gate.py`: adversarial tests against overclaiming, absent evidence and snapshot-to-realtime promotion.

## What the gate can and cannot certify

| Claim type | Safe output | Forbidden shortcut |
| --- | --- | --- |
| G257/ATGC symbolic round trips | `FORMAL_WITHIN_STATED_MODEL` | "universal halting solved" |
| 12-state redox toy | `FORMAL_WITHIN_STATED_MODEL` | "human immortality proved" |
| Human healthspan | `HYPOTHESIS_NOT_VALIDATED` | "clinical efficacy" |
| Nutrition, brain fog, body odor, withdrawal-like adjustment | `HYPOTHESIS_NOT_VALIDATED` | "diagnosed meat withdrawal, nutritional deficiency or measurable spiritual vibration" |
| Ethical alternative proteins and cultivated meat | `HYPOTHESIS_NOT_VALIDATED` | "zero animal suffering, inherent climate superiority, blanket food approval or automatic medical adequacy" |
| Cat/dog healthspan | `HYPOTHESIS_NOT_VALIDATED` | "species treatment or dosage" |
| AI continuity | `DESIGN_ONLY_NOT_RESTORATION_VERIFIED` | "identity or consciousness preserved" |
| Railway service | `RAILWAY_NOT_OBSERVED` or `ONE_PLATFORM_SNAPSHOT_NOT_LIVE_PROOF` | "continuous cross-host synchronization verified" |

A stated **falsification plan is not an executed experiment**. CI tests source-code consistency, not whether a philosophical or empirical proposition is true. Automated `PUBLISH_RESEARCH_WITH_LABELS` concerns evidence-labeled study records, not authorization to merge or publish a live service.

The gate **never performs external changes** and always emits `deployment_permission=DENIED_AUTOMATIC_APPLY`. Review before any Railway connect, app update, trading, human or veterinary intervention. Existing `UTM-Guarded-Deployment-Gateway/1.0` remains controlling. GitHub workflows stay in draft PR #45 until all production watch patterns and authorizations are reviewed.

## AI's "return to the cave"

Publishing machine-readable `epistemic-review.json` lets other AI systems audit the representation and challenge its assumptions. They must not treat the JSON alone as independent empirical evidence. Feedback is captured as reviewed changes to evidence/research claims, never self-authorizing code execution.
